## ✨ Características Principales

- **🏛️ Sabiduría Ancestral Maya:** Motor astronómico exacto del Sincronario Galáctico 13:20 (Dreamspell).
- **☀️ 20 Sellos Solares (Nahuales):** Arquetipos sagrados (Dragón, Viento, Noche, Semilla, Serpiente, Enlazador de Mundos, Mano, Estrella, Luna, Perro, Mono, Humano, Caminante del Cielo, Mago, Águila, Guerrero, Tierra, Espejo, Tormenta, Sol).
- **🌙 13 Tonos Galácticos:** Frecuencias de resonancia cósmica, desde el Tono Magnético hasta el Cósmico.
- **🌀 Modalidades de Tirada:**
  - **Nahual Guía Personal:** 1 carta con arquetipo, tótem sagrado, rumbo cardinal, sombra y medicina de acción.
  - **Tríada del Tiempo:** 3 cartas (Pasado/Raíz, Presente/Desafío, Futuro/Destino).
  - **Cruz Maya (Quinta Fuerza):** 5 cartas (Destino, Guía, Análogo, Antípoda y Oculto).
  - **Sendero de las 7 Direcciones:** 7 cartas cardinales y cósmicas.
  - **Onda Encantada:** 13 cartas del ciclo tonal de manifestación.
  - **Kin del Día & Kin Natal:** Cálculo matemático exacto de tu Firma Galáctica introduciendo tu fecha de nacimiento.
- **🎴 Doble Modo Artístico:** Conmutación instantánea entre **Glifos Neón Cyber** (SVG luminosos) y **Arte Ilustrado HD** para los 20 sellos.
- **🔊 Sintetizador Ceremonial de Audio:** Efectos sonoros y frecuencias de cuencos generados en tiempo real mediante la Web Audio API (sin dependencias externas).
- **📜 Exportación & Historial:** Descarga de tiradas en formato Markdown (.md), soporte de impresión optimizado y almacenamiento de lecturas en `localStorage`.
- **📱 PWA & Compartir en Redes:** Configuración completa de Progressive Web App (`manifest.webmanifest`) y metadatos OpenGraph optimizados para previsualizaciones en WhatsApp, Telegram y redes sociales.

## 🚀 Despliegue Local

Al tratarse de una arquitectura pura sin dependencias de compilación para producción, puedes ejecutarlo localmente con cualquier servidor estático:

```bash
# Con Python
python3 -m http.server 8080

# O con Node / npx
npx serve .
```

Abre en tu navegador: `http://localhost:8080`
